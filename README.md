# LearningPlaywright

Welcome to **LearningPlaywright**! This project is a comprehensive, hands-on guide to mastering JavaScript, TypeScript, and Playwright for modern web automation and testing. It is organized into well-structured chapters, each focusing on a core concept, with practical code examples and exercises.

## 📚 Project Structure

- **chapter_01_Basics**: JavaScript basics and setup
- **chapter_02_Java_Concepts**: Core JavaScript concepts, hoisting, variables, and more
- **chapter_03_Identifier_Literal_Operators_Statement**: Identifiers, literals, operators, and statements
- **chapter_04_Operators**: Deep dive into JavaScript operators
- **chapter_05_Statements**: Control flow and statement examples
- **chapter_06_Switch_Statements**: Switch statement usage and patterns
- **chapter_07_Loops**: Looping constructs in JavaScript
- **chapter_08_Arrays**: Array operations and methods
- **chapter_09_Functions**: Functions and their applications
- **chapter_10_Strings**: String manipulation techniques
- **chapter_11_Objects**: Object-oriented JavaScript
- **chapter_12_Multi_Dimension_Array**: Working with multi-dimensional arrays
- **chapter_13_Callback**: Callbacks and asynchronous patterns
- **chapter_14_Promise**: Promises and async/await
- **chapter_15_Async_Await**: Advanced async/await usage
- **chapter_16_OOps**: Object-oriented programming concepts
- **chapter_18_Typescript**: Introduction to TypeScript
- **chapter_19_Typescript_Interface**: TypeScript interfaces
- **chapter_20_Typescript_ENUM**: TypeScript enums
- **chapter_21_Typescript_Generic**: Generics in TypeScript
- **chapter_22_Typescript_PRIVATE_PROTECTED_PUBLIC**: Access modifiers in TypeScript
- **Playwright_AI_Agents**: Playwright automation with AI agents
- **Playwright_MCP**: Model Context Protocol with Playwright
- **specs/**: Test specifications and Playwright tests
- **Tasks/**, **Test/**: Additional exercises and test files

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone <repo-url>
   cd LearningPlaywright
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Run code examples:**
   - Navigate to any chapter and run JavaScript files using Node.js:
     ```bash
     node chapter_01_Basics/01_basic.js
     ```
   - For Playwright tests, use:
     ```bash
     npx playwright test
     ```
